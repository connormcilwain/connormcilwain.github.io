1. Modelling question

The project treats UFO reports as a large, messy corpus of human observations. The modelling task is not to decide whether an event happened; it is to find repeatable structure in how witnesses describe sightings.

Useful clusters should be dense in feature space, interpretable in plain English, and grounded in representative report snippets.

2. Dataset and usable signal

The raw NUFORC data combines structured fields and free text. The public analysis reports 138,601 dated sightings from 1969-2022, with 426 countries represented. For spatial modelling, the useful subset is smaller: 115,386 reports include geocoded city latitude and longitude.

3. Feature engineering code

The feature pipeline turns weakly structured report data into comparable numeric and categorical signals. The most important choices are removing corpus-wide text terms, parsing free-text duration, and encoding cyclic variables correctly.

Text normalization

Generic sighting words dominate naive topic models. Removing them makes the topic model better at separating specific report types.

STOPWORDS = {"light", "bright", "sky", "object", "ufo", "craft"}

def clean_report_text(text):
    text = str(text).lower()
    text = re.sub(r"https?://\S+", " ", text)
    text = text.translate(str.maketrans("", "", string.punctuation))
    tokens = [
        token for token in text.split()
        if token not in STOPWORDS and len(token) > 2
    ]
    return " ".join(tokens)

Duration parsing

Durations arrive as strings such as 30 sec, about 3 minutes, or 2 hrs. The model converts them to seconds, then uses a log transform to compress the extreme right tail.

def parse_duration_seconds(value):
    text = str(value).lower()
    number = re.search(r"(\d+(?:\.\d+)?)", text)
    if not number:
        return np.nan

    unit_seconds = {
        "sec": 1, "second": 1,
        "min": 60, "minute": 60,
        "hr": 3600, "hour": 3600,
    }

    for unit, multiplier in unit_seconds.items():
        if unit in text:
            return float(number.group(1)) * multiplier

    return np.nan

Cyclic time

Clock time is circular. A raw hour column makes 23:00 and 00:00 look far apart even though they are adjacent. Sine/cosine pairs fix that geometry.

def encode_cyclic_hour(hour):
    angle = 2 * np.pi * hour / 24
    return np.sin(angle), np.cos(angle)

# 23:00 and 00:00 become neighbours on the unit circle.
# They are no longer treated as 23 numeric units apart.

4. Semantic embeddings

Topic models capture recurring word groups. DistilBERT embeddings add a denser semantic representation, so similar reports can sit near each other even when the exact vocabulary differs.

5. Dimensionality reduction before density clustering

DBSCAN depends on distances. In high-dimensional sparse spaces, distances become less meaningful and eps becomes brittle. The experiments compare three compressed feature spaces before clustering.

6. Bayesian hyperparameter tuning for DBSCAN

DBSCAN has two sensitive parameters: eps, the neighborhood radius, and min_samples, the density threshold. Grid search spends too many evaluations on degenerate solutions. Bayesian optimization is more efficient because it uses previous trials to choose the next region to test.

space = [
    Real(0.05, 1.50, name="eps"),
    Integer(5, 80, name="min_samples"),
]

@use_named_args(space)
def objective(eps, min_samples):
    labels = DBSCAN(eps=eps, min_samples=min_samples).fit_predict(X_umap)
    n_clusters = len(set(labels)) - int(-1 in labels)
    noise_share = np.mean(labels == -1)

    if n_clusters < 2 or n_clusters > 30:
        return 1.0
    if noise_share > 0.80:
        return 1.0

    keep = labels != -1
    return -silhouette_score(X_umap[keep], labels[keep])

result = gp_minimize(objective, space, n_calls=60, random_state=42)
GuardrailReason
Reject fewer than 2 clustersA single cluster is not an analysis.

Methodological choice: the final model is selected for interpretable structure, not just the highest numerical score. For this project, a slightly lower metric can be better if the resulting clusters have readable profiles.

Reporting volume

Reports rise sharply after 2000 and peak around 2012-2014, consistent with reporting infrastructure and cultural attention rather than a direct claim about phenomena frequency.

Geography

8. Cluster profiling with delta features

A cluster label is only useful if it can be described. Delta profiling compares each cluster with the dataset baseline and ranks the features that make it different.

def delta_profile(df, labels):
    numeric = df.select_dtypes(include="number")
    overall = numeric.mean()

    rows = []
    for cluster_id in sorted(set(labels) - {-1}):
        cluster_mean = numeric.loc[labels == cluster_id].mean()
        delta = (cluster_mean - overall).sort_values(key=abs, ascending=False)
        rows.append({
            "cluster": cluster_id,
            "top_features": delta.head(8)
        })

    return rows

9. Limits and next steps

The model discovers patterns in reporting, not ground truth about causes. NUFORC reports are self-submitted, culturally mediated, and shaped by changes in access, media attention, and reporting habits.
