WoW Tactics Companion

A voice-activated, AI-powered in-game advisor for World of Warcraft. Hold a hotkey, ask a boss-tactics question out loud, and get a short spoken answer through your headset — all without alt-tabbing out of a raid.

The problem

High-end WoW content punishes hesitation. When you forget a boss mechanic mid-pull, the options are bad: alt-tab to a wiki and die, or ask in voice chat and break everyone's focus. I wanted the answer to come to me — hands on the keyboard, eyes on the screen, spoken into my ear in the time it takes to position for the next cast.

The catch: the target content (Midnight Season 1) postdates the language model's training cutoff, so the assistant can't just "know" the fights. It has to answer only from verified, scraped tactics data — never from the model's own guesses. That constraint shaped the whole architecture.

How it works

1 · Capture

Holding Caps Lock opens the mic. Audio is routed through VB-Audio Virtual Cable so Discord still hears your real mic — no echo, no feedback loop. Captured at the device's native 48 kHz and resampled to 16 kHz.

2 · Transcribe (local, offline)

faster-whisper (base model, int8) runs entirely on-device — no audio leaves the machine and there's no per-request STT cost or network round-trip.

3 · Extract & match

A keyword extractor pulls boss, dungeon, role, and ordinals from noisy speech via a three-stage pipeline: exact substring → fuzzy sliding window (difflib, 0.65 cutoff) → closest-match fallback. So "Pit of Sauron" still resolves to Pit of Saron.

4 · Look up tactics

A local SQLite knowledge base is queried first; on a miss it falls back to live scraping (Icy Veins / Wowhead / Method.gg). Either way the result is labelled verified data.

5 · Answer (Claude, grounded)

The Claude API composes a tight, role-aware reply (~50 words) strictly from the supplied context. Explicit context flags (VERIFIED, NO_CONTEXT, NO_MATCH, KNOWN_INSTANCE_NO_DATA) stop it from inventing mechanics.

6 · Speak + overlay

The answer is spoken via ElevenLabs (or offline pyttsx3) on a non-blocking queue, and mirrored on an always-on-top tkinter HUD showing the question and reply.

Key features

Hallucination-resistant

Answers are grounded in scraped, verified data with explicit context flags — the model is forbidden from answering post-cutoff fights from memory.

Session memory

Remembers your role and current instance across questions, so "what does the second boss do?" just works after you say where you are.

Speech-noise tolerant

Three-stage fuzzy matching and a hand-built alias table absorb the way Whisper mangles fantasy proper nouns.

Ordinal resolution

"First boss of Skyreach", "last boss", "second boss" map to real names using per-instance boss rosters.

Role-aware answers

Tank, healer, and DPS each get advice filtered to their job via role-specific columns in the database.

Non-blocking by design

Async TTS queue and a strict threading model keep the tkinter UI responsive while audio, STT, and the API run off the main thread.

Engineering notes

Grounding the model

The system prompt instructs Claude to answer only from a VERIFIED TACTICS DATA block. When nothing is found, the router sends a flag instead of empty context, so the model asks the user to repeat rather than confabulating a mechanic that doesn't exist.

Fuzzy matching

Real speech is messy. Matching runs exact → fuzzy sliding-window (SequenceMatcher, cutoff 0.65) → get_close_matches as a last resort, balancing precision against Whisper's mishearings of multi-word boss names.

Threading model

The tkinter mainloop owns all UI; audio capture, STT, routing, and TTS run on worker threads. Every overlay update is marshalled back to the main thread via root.after() to stay crash-free.

Data pipeline

A CLI scraper populates SQLite, then an LLM-powered cleaning pass normalises names, splits role notes into columns, and extracts phase info — ~217 tactics rows of structured, queryable data.

Talking to it

You speak naturally; context carries forward between questions.

How do I tank the first boss of Pit of Saron? What should the healer do on Vorasius heroic? Tell me the second boss of Maisara Caverns. I'm tanking The Voidspire. What does the second boss do? Switch to healer perspective.
